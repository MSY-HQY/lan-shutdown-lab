# lan-shutdown-lab

局域网内的双端远程关机**实验**：一台电脑（操作端）在局域网里等，另一台电脑（被控端）主动连回来，操作端发一个字符过去，被控端就关机 / 重启 / 取消。

写给想搞清楚 **socket 双端到底怎么连**、又不想被"黑客教程"绕晕的人。中文注释，两端配对，每个坑都写了实测结论。

> **它不是什么**：不是远控木马，不需要诱骗安装，不能穿透外网，也不能在对方毫无察觉的情况下控制一台电脑——被控端必须**由那台电脑自己运行**，而且两端必须在**同一个局域网**内。
>
> **只在你自己的设备，或**对方明确同意你测试的设备**上运行。**

## 两个版本

| 目录 | 是什么 | 适合谁 |
| --- | --- | --- |
| `src/minimal/` | 改动最少的版本，骨架就是最常见的那种教学代码 | 想一步步看懂的人 |
| `src/full/` | 工程版：执行结果会回话、可换端口、配置记在文件里 | 想拿它当模板写别的东西的人 |

每个目录都是两份：`target.py`（被控端，跑在被关机的那台上）＋ `operator.py`（操作端，跑在你手上这台）。

`src/minimal/target_hardcoded_ip.py` 是把 IP 直接写进代码的版本，对应短视频里那种"改一行、拷过去就能用"的玩法。

## 命令

| 键 | 作用 |
| --- | --- |
| `1` | 关机（`shutdown -s -t 30`，30 秒后执行） |
| `2` | 重启（`shutdown -r -t 30`） |
| `3` | 取消关机／重启（`shutdown -a`） |
| `4` | 只响两声提示音，不动电源（用来验通路） |
| `5` | 查对方主机名和 IP（仅工程版） |
| `9` | 断开这次连接（仅工程版） |
| `q` | 退出操作端 |

## 两台电脑怎么跑

1. 两台连同一个 WiFi／交换机。先在**操作端**那台上运行：

   ```bash
   python operator.py
   ```

   它会打印本机的局域网 IP，例如 `192.168.1.10`。

2. 到**被控端**那台上运行，把这个 IP 填进去：

   ```bash
   python target.py 192.168.1.10
   ```

   不带参数也行，它会问你一次，然后把答案记进旁边的 `被控端配置.txt`。

3. 顺序随便——被控端连不上会每 3 秒重试一次。

4. **先用 `4` 验通路**（对方响提示音），确认通了再试 `1`。关机有 30 秒倒计时，来得及发 `3` 取消。

5. 操作端第一次运行时 Windows 防火墙会弹窗，选「专用网络」并允许；没弹窗又连不上，就手动放行 TCP 4444 入站。

## 为什么"只关到自己电脑"

这是这类代码最常见的翻车方式，值得单独说：被控端里的 `s.connect((IP, 4444))` 填的是**操作端那台电脑**的地址。如果那个位置写了一个本机地址（比如 VMware 虚拟网卡自动分配的 `169.254.x.x`），被控端就会连回自己，命令绕一圈关掉自己的机器。

判断方法：看被控端启动时打印的「操作端：」后面那个 IP，是不是**另一台电脑**的地址。是 `127.0.0.1`、`169.254.*`、或者这台机自己的 IP，都说明填错了。

## 实测踩到的坑

- **`winsound.Beep()` 在很多笔记本上不出声**，插着耳机更听不到——它走的是老式 Beep API。要"能听见"就用 `winsound.PlaySound("SystemExclamation", winsound.SND_ALIAS)`，它才走真正的音频设备。
- **中文 Windows 下 `shutdown` 的输出是 GBK**，`subprocess` 里用 `text=True` 按 UTF-8 解会当场 `UnicodeDecodeError` 把程序崩掉。要写 `encoding="mbcs", errors="replace"`，并且判断成功用 `returncode`，别去 grep 中文输出里的关键字。
- **`os.system()` 可以直接用**，但如果用 `subprocess` 记得处理 `stdout/stderr` 可能是 `None` 的情况。
- **`accept()` 阻塞时读不到键盘**。操作端如果在一段连接结束后直接回去 `accept()`，那个"按 q 退出"就永远读不到——断开后先 `input("回车＝继续，q＝退出")`，再回去等。
- **对端被强行关掉时 `recv()` 会抛 `ConnectionResetError`（10054）**。不 try/except 的话整个被控端会直接退出，用户以为是"程序崩了"。包起来，回到外层重连。
- **PyInstaller `--onefile` 打出来的 exe 启动要几秒**（解包），黑窗口停住不是卡死。另外这类 `socket + shutdown` 组合常被 Defender／杀软盯上，可能直接被删——这不是代码写错了。
